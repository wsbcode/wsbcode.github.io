# 💼 Portfólio - William Barbosa

Portfólio profissional desenvolvido para demonstrar minhas habilidades como Desenvolvedor Full Stack, com foco em design moderno, performance e experiência do usuário.

---

## 💻 Sobre

Este portfólio foi construído com React, Vite e Tailwind CSS, seguindo boas práticas de componentização, código limpo e design responsivo.

Cada seção foi pensada para apresentar minha trajetória, habilidades técnicas e projetos de forma clara e atrativa.

---

## 🚀 Seções

### 🧭 Navbar

* Navegação fixa com scroll suave
* Menu hambúrguer no mobile
* Glassmorphism ao scrollar

### 👋 Hero

* Apresentação pessoal com animações
* Foto profissional com moldura gradiente
* CTAs para projetos e contato

### 👤 Sobre Mim

* Minha trajetória na programação

### 🛠️ Habilidades

### 📁 Projetos
